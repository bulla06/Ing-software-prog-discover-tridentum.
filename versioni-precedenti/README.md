# Versioni precedenti del sito

Copie delle versioni passate della web app, conservate come riferimento (per esempio per mostrarle all'esame o confrontarle con la versione attuale). Non si modificano: il lavoro si fa in [`versione-corrente/`](../versione-corrente).

| Versione | Cartella | Data | Contenuto |
|---|---|---|---|
| 1 | [`v1-prototipo/`](v1-prototipo) | 7 ottobre 2026 | Primo prototipo: solo frontend, dati in file JSON, nessun account |

Ogni versione ha un suo README con le istruzioni per avviarla. La storia completa di ogni file resta comunque in Git.

**Per archiviare la versione corrente** quando ne inizia una nuova: copiare `versione-corrente/frontend` (ed eventualmente `versione-corrente/backend`) in una cartella `vN-nome/`, aggiungere il README e una riga a questa tabella.
