# Versione corrente del sito

La web app su cui lavora il team: **frontend** ([`frontend/`](frontend), React + Vite) e **backend** ([`backend/`](backend), Node.js + Express con database PostgreSQL + PostGIS).

Si avvia dalla cartella principale del repository, non da qui:

```bash
npm install
npm run dev        # sito su http://localhost:5173
npm test
```

Istruzioni complete, account di prova e avvio con Docker nel [README principale](../README.md#il-sito). Le versioni passate sono in [`versioni-precedenti/`](../versioni-precedenti).
